# Durga Pujo

Run: `ADMIN_PASSWORD=yourpass node server.js` -> http://localhost:3000

Copy your original `public/images/` folder (hero-pandal.jpg, covers/*.jpg) into `public/images/`.
Demo audio: `node scripts/gen-audio.mjs` (already generated in public/audio).
Env: ADMIN_PASSWORD, SESSION_SECRET, DATA_DIR (set to a persistent disk path when deploying).
